## Agent skills

### Issue tracker

Issues 與 spec 放在 GitHub Issues（wide3751/skillboard），用 `gh` CLI 操作。See `docs/agents/issue-tracker.md`.

### Triage labels

沿用五個預設標籤（needs-triage、needs-info、ready-for-agent、ready-for-human、wontfix）。See `docs/agents/triage-labels.md`.

### Domain docs

Single-context：根目錄一份 `GLOSSARY.md` + `docs/adr/`。See `docs/agents/domain.md`.
